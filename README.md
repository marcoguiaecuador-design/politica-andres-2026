# Observatorio municipal de Montúfar

Análisis documental de seis planes electorales aportados, competencias municipales, COOTAD y Código de la Democracia, y seguimiento ciudadano de la gestión 2023–2027. Corte documental: 23 de noviembre de 2026. Versión 1.10, con el filtro Eje 1 corregido.

**[Abrir el observatorio](https://marcoguiaecuador-design.github.io/politica-andres-2026/)**

El repositorio y la página son públicos. No se certifica aquí la nómina oficial del CNE. Se comparan las copias recibidas sin ranking político; ausencia de presupuesto electoral no es indicador de evaluación. Contratación, recepción y funcionamiento de obras se distinguen expresamente.

## Contenido

- `docs/observatorio/informe.html`: página interactiva con datos integrados.
- `docs/observatorio/datos.json`: versión publicada para consulta e importación.
- `docs/observatorio/fuentes_publicacion.json`: registro de las 96 fuentes y sus enlaces originales.
- `scripts/preparar_observatorio.py`: prepara una edición para compartir desde el expediente local.
- `docs/PUBLICACION.md`: alcance de la revisión y procedimiento de actualización.

## Revisiones del equipo

Para proponer una corrección, indicar candidato o sección, identificador de ficha, fuente oficial, página, fecha y cambio sugerido. Puede registrarse en [Issues](https://github.com/marcoguiaecuador-design/politica-andres-2026/issues). No publicar información personal o interna.

Las notas y ediciones de la página quedan en el navegador de cada persona. **Exportar datos o HTML no actualiza GitHub ni sincroniza las notas del equipo.** Las revisiones se integran tras contrastar las fuentes y guardar una nueva versión en el repositorio. Para cargar una revisión en un navegador con datos guardados: exportar primero las notas y luego importar `datos.json` desde «Actualizar expediente».

La publicación se sirve desde `main` → `/docs` en GitHub Pages. Cada actualización de esa carpeta se vuelve a publicar en la misma dirección.
