# Criterios para incorporar datos

## Regla principal
Los archivos de trabajo no se suben automáticamente. Cada conjunto debe revisarse antes de entrar al repositorio.

## Revisión mínima
1. Identificar la fuente y comprobar que su uso sea legítimo.
2. Eliminar nombres, teléfonos, correos, direcciones e identificadores.
3. Evitar combinaciones de variables que permitan reconocer a una persona.
4. Trabajar con resultados agregados cuando sea posible.
5. Conservar los originales únicamente en el almacenamiento autorizado.
6. Documentar fecha, fuente, transformación y responsable de la revisión.

## Contenido adecuado para GitHub
- datos públicos y agregados;
- diccionarios de variables;
- plantillas sin respuestas;
- scripts de limpieza o análisis;
- documentación metodológica;
- resultados anonimizados;
- visualizaciones sin información personal.

## Contenido excluido
- respuestas individuales;
- bases de contactos;
- credenciales;
- datos financieros;
- archivos de respaldo;
- información personal sensible;
- perfiles o segmentación individual.

## Publicación
El repositorio debe permanecer privado. Cualquier publicación externa requiere una revisión separada del contenido y de los permisos.
